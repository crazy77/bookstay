해묘서가 가이드 `data/food-spots.tsx`에 등재된 **22곳**을 대상으로, 인터넷에서 찾을 수 있는 **사진·이미지 출처**와 **사이트에 실제로 쓸 수 있는지**를 정리했습니다.

## 요약 (먼저 읽기)

| 구분 | 설명 |
|------|------|
| **바로 쓰기 어려움** | 네이버 플레이스·블로그·인스타·다이닝코드·트립닷컴 리뷰 사진 → 업로더/매체 저작권. 무단 저장·재게시는 침해 소지가 큼. |
| **허가 후 가능성 높음** | 각 업체 공식 인스타·홈페이지·쇼핑몰 → **사장님/마케팅 담당에게 DM·전화로 2차 사용 허락** 요청. |
| **공식·관광 쪽** | [비짓제주 사형제횟집](https://www.visitjeju.net/kr/detail/view?contentsid=CNTS_000000000020819) 등 일부 등재 업체 → **제주관광공사 사진 사용 문의** 필요 (상업 웹 게시는 별도 허가). |
| **가장 안전** | **호스트 직접 촬영** 또는 방문 시 업체에 “가이드 페이지용 1~2장” 요청. |

> 이 문서의 링크는 **참고·허가 협의용**입니다. 링크의 이미지를 그대로 `public/`에 넣지 마세요.

## 사진을 찾는 1차 채널 (공통)

1. **네이버 지도·플레이스** — `map.naver.com` / `m.place.naver.com` → 사진 탭 (리뷰·업체 등록 사진 다수)
2. **다이닝코드** — `diningcode.com/profile.php?rid=...` (음식·외관 사진, 저작권은 다이닝코드·제공자)
3. **비짓제주** — `visitjeju.net` (관광 DB, 일부 업체만 등재)
4. **Fun제주 도민맛집** — `funjeju.com` (비타민국수 등 소수)
5. **블로그·인스타·Trip.com** — 양질의 참고용, **재사용은 거의 항상 불가** (허락 없을 때)

## 저작권·활용 체크리스트 (사이트 반영 전)

- [ ] **직접 촬영** — 상업적 이용·수정·크롭 모두 자유.
- [ ] **업체 허가** — 카카오톡/전화/인스타 DM으로 “해묘서가 이용 가이드(비영리 안내 페이지)에 사진 1장 사용” 문구 + 출처 표기 합의.
- [ ] **비짓제주** — [제주관광공사 Q&A: 사진 사용 허가](https://ijto.or.kr/korean/Bd/view.php?bno=1557&btable=qna) 유형 문의 · Tel. 064-740-6000.
- [ ] **공공데이터** — [제주 관광 사진 콘텐츠(data.go.kr)](https://www.data.go.kr/data/3067776/fileData.do)는 **관광 풍경 위주**이며 맛집 개별 메뉴 사진과는 거의 무관.
- [ ] **하지 말 것** — 네이버·블로그·인스타 이미지 URL hotlink, 스크린샷 무단 업로드, “출처: 네이버”만 적고 사용 (저작권 치유 안 됨).

## 구현 제안 (다음 단계)

가이드 UI에 사진을 넣을 경우:

1. `FoodSpotData`에 `image?: { src: string; alt: string; credit?: string }` 추가.
2. `public/assets/food/`에 **허가·직촬영본만** WebP로 저장 (`next/image` 권장).
3. 우선순위: **사형제·등대 아구찜·마이크로 하비타트·부아르** 등 카피가 긴 곳 4~6곳만 썸네일.
4. 사진 없는 곳은 현재처럼 텍스트만 유지.
